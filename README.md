# CourseLens · 课表镜

课表镜是一款轻量的 Android 课表应用，帮助你查看每周课程、上课地点和任课老师，并整理自己的排课信息。浅色界面搭配彩色课程卡片，已导入的课表可以离线查看。

当前版本为 **2.4**，支持 **Android 8.0 及以上**。学校课表同步目前适配 **宿迁学院**，其他学校可使用手动添加课程功能。课表镜是独立应用，并非学校官方应用。

## 下载与安装

前往 [下载页面](https://github.com/fangfar/CourseLens-public/releases/latest)，下载 `CourseLens-2.4-vc6.apk`，传到手机后安装。

- 首次安装时，按系统提示允许浏览器或文件管理器安装该应用。
- 更新时优先直接覆盖安装，保留本机课表。
- 如果系统提示无法覆盖安装，请先保存重要课程信息，不要直接卸载旧应用，以免丢失课表。

## 主要功能

- **按周查看课表**：左右滑动切换教学周，查看当周课程；没有课程时显示文字提示。
- **查看课程详情**：查看课程名称、教室、任课老师、节次、上课时间和教学周次。
- **同步学校课表**：主动登录宿迁学院账号，导入整学期排课；同步失败时保留已有课表。
- **添加与校对课程**：填写课程、老师和教室，选择星期、起止节次与教学周，支持全选、单周和双周。
- **调整学期设置**：选择教学周、设置开学日期，并管理本地课程。
- **保留浏览位置**：从课程详情或设置返回时，恢复原先的周次和课表滚动位置。

## 开始使用

1. 打开应用，点击右上角同步按钮，使用学校 VPN / 网上办事大厅账号导入课表；也可点击 `＋` 手动添加课程。
2. 在设置中确认开学日期，确保当前教学周计算准确。
3. 左右滑动查看不同周次，点击课程卡片查看完整信息。
4. 如需调整课程，使用详情页的校对入口或设置中的课程管理。

**重新同步会以学校数据覆盖本机手动修改的课程。** 返回或取消课程编辑不会保存修改；清空课表需要确认。

## 数据与隐私

课表、备注、所选周次和开学日期保存在本机。应用不会长期保存学校账号或密码，也不会在启动时自动打开登录页；仅在你主动同步时向学校服务发送登录信息。

课表不会通过系统备份自动恢复或迁移到新手机。更换手机、卸载应用或清空应用数据前，请自行保存重要课程信息。

## 使用提示

- 自动同步目前仅适配宿迁学院；学校服务变化时可能需要更新应用或手动校对。
- 教学周支持 1–30 周，节次支持 1–12 节。上课时间采用内置学校作息表，请根据实际安排核对。
- 当前提供中文界面。同步后建议对照学校课表确认课程、周次和地点。
