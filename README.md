# Morrow

Android 校园助手：周课表、作业任务、快递取件码和桌面小组件。支持 Android 8.0 及以上。

[官网与下载](https://morrow.xvyan.cn/) · [版本与更新记录](https://github.com/fangfar/Morrow/releases/latest) · [问题反馈](https://github.com/fangfar/Morrow/issues)

## 功能

- **课表**：按周查看、切换多份课表、编辑课程、单次调课与停课、选择冲突课程；支持桌面小组件，已导入课表可离线查看。宿迁学院、徐州工程学院可学校导入，其他学校可手动添加。
- **任务**：手动添加或连接学习通同步作业，按课程分组显示截止时间；支持本地编辑、自动刷新和删除恢复。验证码与机构认证尚未适配。
- **快递**：管理取件码，支持手动添加、粘贴文字、图片识别和经授权的通知识别；提供官方身份码入口与取件提醒。

介绍对应当前源码，已发布版本的能力以 Releases 为准。

## 安装与使用

从官网或 Releases 下载 APK。图片识别需要另装可选插件。

1. 课表页右上角菜单 → 新增课表，选择手动创建或学校导入；通过“切换课表”使用已有课表。
2. 侧栏 → 设置 → 开学日期；课表页右上角菜单 → 作息时间。导入后核对课程、周次和地点，重新同步会覆盖手动修改。
3. 任务页加号添加任务；点击同步状态配置学习通或刷新作业。更多菜单提供账号、课程、自动刷新和任务恢复。
4. 快递页“读取信息”可粘贴文字或选择截图，核对识别结果后保存。通知识别需在快递设置中开启并授权。
5. 侧栏 → 设置 → 桌面小组件，或在桌面的小组件列表选择 Morrow。尺寸及刷新时机取决于系统与启动器。

## 数据与隐私

课表、任务、快递和设置保存在本机。学校账号密码在登录成功后按课表使用 Android Keystore 加密保存；学习通账号密码在验证成功后加密保存，用于对应平台的验证与刷新。同步失败保留已有数据。切换学习通账号使用各自的本机缓存，手动任务独立保存。

通知识别默认关闭，需要应用内同意和系统通知访问授权；只解析选定来源，不保存通知全文，不读取短信数据库。图片在本机识别，不上传；插件可单独卸载。桌面显示取件码与地址需单独开启。

应用通过 HTTPS 获取公告、版本和插件配置，不向这些服务上传课表、账号或密码。徐州工程学院当前教务入口使用 HTTP；密码按学校协议使用 RSA 加密，但账号、课表和会话传输未受 HTTPS 保护，请在可信网络中同步。

课表不会通过系统备份自动迁移。更换手机、卸载或清空应用数据前，请保存重要信息。
